# Krypton Training Server

Public project layout:

- `docs/` — documentation and setup notes
- `plugin/src/main/java/` — SeasonCraftCore source code
- `plugin/src/main/resources/` — plugin metadata
- `server/` — safe configuration examples
- `plugins/` — optional built plugin artifact

Private worlds, player data, logs, backups, credentials, FTP details, private IPs, and third-party server files are intentionally excluded.
